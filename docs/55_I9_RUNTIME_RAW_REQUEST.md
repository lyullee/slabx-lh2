# 55. i9 계산시간 원자료 재측정 요청서

> **완료 — 2026-08-29.** 요구한 i9-12900K / slabx-lh2 0.1.3 실행은
> `paper_results/runtime_i9_0.1.3/`에 보존됐습니다. 380행, 실패 0건,
> p99/p50 1.015–1.092이며 내부 해시와 독립 통계 재계산이 모두 일치합니다.
> 최종 수치와 인용 규칙은 문서 60을 사용합니다.

## 목적

논문에 사용할 i9-12900K 계산시간의 **반복별 원자료**를 남긴다. 현재 보관된
`paper_results/runtime_reference_summary.csv`는 완성된 요약표를 옮긴 것이며,
반복별 CSV가 없어 재현성 자료로는 불완전하다. 물리 계산은 끝났고, 이 작업은
성능 수치의 provenance만 보완한다.

## 실행 조건

- CPU: 논문에 표기할 Intel Core i9-12900K 워크스테이션
- Python: 3.12 계열 권장
- `slabx`: 1.0.6
- `slabx-lh2`: 이 저장소의 0.1.3
- 전원 연결, 다른 해석·렌더링·대용량 복사 작업이 없는 상태
- 순차 계산만 실행한다. 병렬 수치는 산포가 커 논문에서 사용하지 않는다.

## 실행

저장소 최상위에서 PowerShell로 다음 한 줄만 실행한다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_i9_benchmark.ps1
```

프로젝트의 `.venv`가 있으면 그 Python을 자동으로 사용한다. 다른 환경을 명시할
때는 `-Python C:\path\to\python.exe`를 덧붙인다.

스크립트는 기존 결과를 덮어쓰지 않는다. 같은 이름의 출력 폴더가 있으면 그
폴더를 보존한 채 중단한다.

## 생성 파일

`paper_results/runtime_i9_0.1.3/` 아래에 다음이 있어야 한다.

- `runtime_raw.csv`: 반복별 시간, 상태, LFL 거리, 오류
- `runtime_summary.csv`: p50, p95, p99와 실패 수
- `environment.txt`: CPU·운영체제·Python·패키지 버전
- `validation.txt`: 항목별 행 수·실패 수·p99/p50 자동 검사 결과
- `SHA256SUMS.txt`: 위 파일들의 해시

## 합격 조건

| 항목 | 요구값 |
|---|---:|
| FFI 4·6, NASA 6 단일 예측 | 각각 n = 100 |
| FFI 6건 일괄 | n = 30 |
| 35 시나리오 순차 일괄 | n = 30 |
| cold start | n = 20 |
| 모든 행의 실패 | 0 |
| 인용할 각 순차 지표의 p99/p50 | 1.30 이하 권장 |

p99/p50이 1.30을 넘으면 수치를 버리지 말고 폴더 전체를 그대로 전달한다.
백그라운드 부하 여부를 확인한 뒤 새 출력 폴더명으로 다시 측정한다.

## 논문 반영 규칙

과거 73.2 ms, 153.3 ms, 4.413 s는 **0.1.2 이력값**이며 더 이상 인용하지
않는다. 최종 0.1.3 p95는 각각 65.649 ms, 149.077 ms, 4.197 s다. 본문·표·초록은
문서 60과 동일하게 유지하고, 병렬 결과와 다른 컴퓨터의 결과는 혼합하지 않는다.
